## 역할

**Sheet**는 화면 **가장자리**에 붙은 패널이 오버레이 위로 슬라이드되어 나타나는 컴포넌트입니다. 중앙에 띄우는 모달과 달리, **한 방향(위·아래·왼쪽·오른쪽)**을 기준으로 열리는 점이 특징입니다.

앱에서 **보조 패널**, **옵션·필터 영역**, **짧은 폼이나 목록**처럼 본문을 가리지 않고 한쪽 축으로만 덮고 싶을 때 쓰기 좋습니다. 내용은 `children`으로 자유롭게 구성합니다.

## 열기·닫기

- **열기**: 보통 트리거의 `onClick` 등에서 `isOpen`을 `true`로 둡니다.
- **닫기**: `closeOnBackdropClick`이 켜져 있으면 **딤(반투명 배경)** 클릭 시 `onClose`가 호출되고, **Esc**로도 닫힙니다. 패널 안에서 `onClose`를 호출하는 패턴도 같이 씁니다.
- **스크롤**: 열려 있을 때 `document.body`의 스크롤을 막습니다.

## `direction`

패널이 붙는 변입니다. 기본값은 `bottom`입니다.

- `top` / `bottom`: 상·하단 바 형태
- `left` / `right`: 좌·우 사이드 패널 형태

## `size`

해당 방향에서의 **너비 또는 높이** 스케일입니다. 기본값은 `full`입니다.

- `full`: 해당 축으로 화면을 꽉 채움
- `half`: 뷰포트의 절반 정도(`50vh` / `50vw`)
- `auto`: 내용에 맞추되 최대 `90vh` / `90vw`까지

고정 픽셀(예: 우측 패널 `320px`)이 필요하면 `size="auto"`(또는 축에 맞게 선택)와 함께 `className`으로 `w-[320px]`, `h-[320px]` 등을 주면 됩니다.

## 애니메이션·언마운트

열릴 때와 닫힐 때 패널은 **슬라이드**, 배경은 **페이드**로 전환됩니다. 닫힌 뒤에도 짧게 DOM에 남아 `useDelayUnmount`로 마무리 애니메이션을 보장합니다.
